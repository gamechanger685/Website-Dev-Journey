📘 Meta Tags — Complete Guide

Meta tags = Metadata jo browser, search engines, aur social media ko page ke baare mein batati hai. User ko screen par nazar nahi aati lekin peeche kaam karti hai — SEO, social sharing, performance, security.

1. Charset — Character Encoding

<meta charset="UTF-8">
  • Zaroori: Haan — hamesha lagao
  • Position: Head ka pehla tag
  • Kyun: Urdu, Arabic, Chinese sab characters sahi dikhein
  • Value: Hamesha UTF-8

3. SEO Meta Tags

Description

<meta name="description" content="...">

Google search mein neeche wala text. 150-160 characters.

Keywords (Purana)

<meta name="keywords" content="HTML, CSS, JS">
Aaj kal Google keywords ko ignore karta hai. SEO fayda nahi. Sirf historical reference ke liye.

Robots

<meta name="robots" content="index, follow">
ValueMatlab
indexSearch mein dikhao
noindexSearch mein mat dikhao
followLinks follow karo
nofollowLinks follow mat karo
noarchiveCache mat karo
nosnippetSearch mein snippet mat dikhao
max-snippet:-1Unlimited snippet length

Author, Language, Copyright

<meta name="author" content="Abu Bakar">
<meta name="language" content="English">
<meta name="copyright" content="© 2026 Abu Bakar">
<meta name="revisit-after" content="7 days">

7. Security Meta Tags

<meta http-equiv="X-Content-Type-Options" content="nosniff">
<meta http-equiv="X-Frame-Options" content="DENY">
<meta http-equiv="Content-Security-Policy" content="default-src 'self'">
<meta http-equiv="Referrer-Policy" content="strict-origin-when-cross-origin">
Yeh tags server headers se behtar hain. Sirf meta par depend mat karo — nginx ya Express mein proper headers set karo.

8. http-equiv (Purana Tareeqa)

http-equiv HTTP headers ko simulate karta hai. 90% cases mein server-side headers better hain.

<!-- Refresh (avoid) -->
<meta http-equiv="refresh" content="5;url=https://example.com">

<!-- Charset (purana, HTML5 se pehle) -->
<meta http-equiv="Content-Type" content="text/html; charset=UTF-8">
Refresh kabhi mat use karo. UX bura, accessibility fail. Redirect ke liye server-side ya JavaScript use karo.

10. DevTools Commands

Console (F12) kholo aur yeh commands chalao:

// Saare meta tags
document.querySelectorAll('meta');

// Specific meta
document.querySelector('meta[name="description"]').content;

// Open Graph
document.querySelector('meta[property="og:title"]').content;

// Charset
document.characterSet;

// Title
document.title;

// Meta count
document.querySelectorAll('meta').length;
