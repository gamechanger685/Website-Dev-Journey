🏷️ Title Tag — Complete Guide

Title tag = Page ka naam. Browser tab, bookmarks, Google search, social media — sab mein dikhta hai. Yeh HTML ka sab se important SEO element hai.

1. Kahan Kahan Dikhta Hai?

  • Browser tab mein (top par)
  • Bookmarks mein (jab save karo)
  • Google search results mein (blue link)
  • Social media share previews mein
  • Screen readers page load par announce karte hain
  • Windows taskbar mein
  • Browser history mein

5. Title Tag Best Practices

✅ Yeh Karo:

  • Primary keyword shuru mein rakho
  • Brand name aakhir mein (| Brand)
  • Har page par unique title
  • Descriptive aur specific
  • Emoji sirf jab relevant ho (🚀, ✅)
  • Numbers use karo ("10 Tips", "2026 Guide")
  • Title case ya sentence case consistent rakho

❌ Yeh Mat Karo:

  • Keyword stuffing ("HTML HTML HTML")
  • Same title har page par
  • Generic titles ("Home", "Page 1")
  • ALL CAPS (except acronyms)
  • Special characters se spam
  • Clickbait ("You Won't Believe...")

7. Unicode & Special Characters

Title mein Unicode support hai (UTF-8 charset ki wajah se):

<title>اردو ٹائٹل | Abu Bakar</title>
<title>中文标题 | Abu Bakar</title>
<title>Titre Français | Abu Bakar</title>
<title>🚀 Rocket Emoji Title</title>
Dhyan rakho: Emoji aur Unicode characters 1 character nahi, multiple bytes hote hain. Character count par asar padta hai.

8. Dynamic Titles (SPAs & SSR)

JavaScript Se Change Karo:

// Simple DOM manipulation
document.title = "New Page Title — Abu Bakar";

// Check current title
console.log(document.title);

React Helmet (React SPA):

import { Helmet } from 'react-helmet-async';

function BlogPost({ title }) {
  return (
    <>
      <Helmet>
        <title>{title} | Abu Bakar</title>
      </Helmet>
      <h1>{title}</h1>
    </>
  );
}

Next.js App Router (SSR):

// Static
export const metadata = {
  title: 'About | Abu Bakar'
};

// Dynamic
export async function generateMetadata({ params }) {
  const post = await getPost(params.slug);
  return {
    title: `${post.title} | Abu Bakar`
  };
}

13. Accessibility Impact

Screen readers page load hote hi <title> ko sab se pehle announce karte hain. Yeh visually impaired users ke liye page ka pehla impression hai.

Best Practices for A11y:

  • Descriptive title (naam, purpose clear ho)
  • Front-load important info
  • Page change ho to title update karo (SPA)
  • Same title use mat karo across pages

14. SEO Impact

Title tag Google ka #1 on-page SEO factor hai. Poori page par title se zyada weight kisi cheez ka nahi.

SEO Rules:

  • Primary keyword shuru mein (ya shuru ke qareeb)
  • Secondary keyword natural jagah
  • Brand name aakhir mein
  • Click-through rate (CTR) badhata hai
  • Search results mein bold/blue dikhta hai
  • Title = Google ka page ka "headline"
