🏠 Homepage

Formula: Brand — Tagline | Keywords
Pattern: [Brand] — [What You Do] | [Tech Stack]
Abu Bakar — Full Stack Web Engineer | Next.js · NestJS · AI 56 chars
Why: Brand pehle, phir role, phir tech stack. Search mein brand recognition + keyword coverage dono milte hain.

👤 About Page

Formula: About [Person/Company] — [Detail]
Pattern: About [Name] — [Role] · [Location]
About Abu Bakar — Software Engineer · Pakistan 47 chars
Why: "About" keyword search volume high hai. Location add karo for local SEO.

📚 Blog List Page

Formula: Blog — [Topic] | [Brand]
Pattern: Blog — [Category] | [Brand]
Blog — Web Development Tutorials | Abu Bakar 47 chars
All Posts — Full Stack Development | Abu Bakar 46 chars
Why: "Blog" aur category dono important. Brand last mein trust ke liye.

📝 Blog Post (Dynamic)

Formula: [Post Title] | [Brand]
Pattern: [Specific Topic] — [Year] | [Brand]
Complete Guide to HTML Meta Tags — 2026 | Abu Bakar 51 chars
10 CSS Grid Tricks Every Developer Should Know | Abu Bakar 57 chars
How to Build a REST API with NestJS — Step by Step 52 chars
Why: Post title = primary keyword. Year add karo (freshness signal). Brand last mein.

🛍️ Product Page

Formula: [Product] — [Feature] | [Brand]
Pattern: [Product Name] — [Key Benefit] · [Price]
Next.js Course — Master Modern React | Abu Bakar 48 chars
Premium Portfolio Template — Built with Next.js 49 chars
Why: Product name + benefit + brand. Price add karo agar competitive advantage ho.

💰 Pricing Page

Formula: Pricing — [Plans] | [Brand]
Pattern: Pricing — [Plan Types] | [Brand]
Pricing — Free, Pro & Enterprise Plans | Abu Bakar 49 chars
Why: "Pricing" + plan names search mein popular. Specific plans mention karo.

📖 Documentation Page

Formula: [Topic] Docs — [Detail] | [Brand]
Pattern: [Function/API] — [What It Does] | Docs
useEffect Hook — React Docs | Abu Bakar 38 chars
Authentication API — Complete Reference | NestJS Docs 53 chars
Why: Developers exact names search karte hain. Function/API name pehle rakho.

🔐 Authentication Pages

Login / Signup / Reset Password
Sign In — Abu Bakar 19 chars
Create Account — Join Abu Bakar 31 chars
Reset Password — Abu Bakar 26 chars
Why: Auth pages usually noindex hote hain, lekin accessibility ke liye title zaroori hai.

📊 Dashboard / App

Formula: [Section] — [App Name]
Dashboard — My App 17 chars
Analytics — Q4 2026 | My App 26 chars
Settings — Profile | My App 25 chars
Why: SPA mein dynamic title change karta hai as user navigates. Screen reader announcement ke liye important.

🚫 404 Error Page

Formula: [Error] — [Page] | [Brand]
Page Not Found (404) — Abu Bakar 31 chars
Why: 404 title clear hona chahiye. User ko pata chale kya hua.

💡 Pro Tips

✅ Do:
  • Primary keyword front-load karo
  • Brand name pipe (|) se separate karo
  • Har page unique title
  • Year include karo (2026) freshness ke liye
  • Numbers use karo — CTR badhata hai
  • Emoji sparingly — sirf jab relevant ho
❌ Don't:
  • Keyword stuff karna
  • Duplicate titles across pages
  • ALL CAPS except acronyms
  • Clickbait phrases
  • Ignore character limit
