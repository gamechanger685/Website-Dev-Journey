🎬 Body Element — Complete Guide

Body element = HTML document ka visible container. Jo bhi user screen par dekhta hai — text, images, buttons, forms — sab <body> ke andar hota hai.

1. Basic Structure

<!DOCTYPE html>
<html lang="en">
<head>
  <!-- Metadata -->
</head>
<body>
  <!-- Visible content -->
</body>
</html>
  • Ek page par sirf ek body
  • Head ke baad aata hai
  • HTML ke andar last element
  • Sab visible content iske andar

load vs DOMContentLoaded

document.addEventListener('DOMContentLoaded', () => {
  // HTML ready — saare elements accessible
  console.log('DOM ready');
});

window.addEventListener('load', () => {
  // Sab kuch ready — images bhi
  console.log('Everything loaded');
});
Rule: DOM manipulation ke liye DOMContentLoaded use karo. Faster hai.

5. Body Ka Default Styling

Browsers body ko kuch default styles dete hain:

/* Chrome/Safari default */
body {
  display: block;
  margin: 8px;
}

/* Firefox same, Edge same */
Yeh 8px margin aksar designers ko pareshan karta hai. Isi liye CSS reset common hai: 
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

9. Body Structure (Best Practice)

<body>
  <!-- Skip link for accessibility -->
  <a href="#main" class="skip-link">Skip to content</a>

  <!-- Header -->
  <header>
    <nav>...</nav>
  </header>

  <!-- Main content -->
  <main id="main">
    <article>...</article>
    <aside>...</aside>
  </main>

  <!-- Footer -->
  <footer>...</footer>

  <!-- Scripts at end -->
  <script src="app.js"></script>
</body>

11. Body vs document.body

// HTML element
<body class="dark">

// JavaScript access
document.body;            //  element
document.body.className;  // "dark"
document.body.innerHTML;  // HTML content

// Common gotcha
document.body === document.querySelector('body');  // true
document.body === document.documentElement;        // false ()

12. Body Aur SEO

Body mein content SEO ke liye zyada important hai, lekin meta tags (head mein) search appearance control karte hain.

SEO Best Practices:

  • Semantic tags use karo (<main>, <article>, <nav>)
  • Heading hierarchy theek rakho (h1 → h2 → h3)
  • Ek <main> per page
  • Content meaningful aur structured ho
  • Images mein alt zaroori
  • Links descriptive text ke saath

13. Body Aur Accessibility

Body accessibility: Screen readers body ke andar ke content ko structure ke hisaab se padhte hain. Semantic HTML accessibility ka base hai.

Key Considerations:

  • Skip links — Pehla focusable element
  • Landmark roles — header, nav, main, aside, footer
  • Heading order — h1 se h6 tak hierarchical
  • Focus management — Keyboard navigation support
  • Color contrast — 4.5:1 text, 3:1 UI elements
  • Alt text — Images ke liye zaroori
