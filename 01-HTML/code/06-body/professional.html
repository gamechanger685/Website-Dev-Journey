Body Structure Ka Best Practice

Ek professional HTML body mein yeh elements is order mein hote hain:

  1. Skip link — Pehla focusable element (accessibility)
  2. <header> — Logo, navigation, branding
  3. <main> — Primary content (sirf ek per page)
  4. <footer> — Copyright, links, secondary info
  5. <script> — JavaScript (end mein)

Yeh structure SEO, accessibility, aur maintainability ke liye best hai.
