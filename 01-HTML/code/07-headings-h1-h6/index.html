📑 Headings h1-h6 — Complete Guide

Heading tags HTML document ka outline banate hain. Yeh document ka structure, SEO ranking, aur accessibility — teenon ke liye critical hain.

3. Heading Hierarchy (Correct Way)

<h1>Page Title</h1>

<h2>Section 1</h2>
  <h3>Subsection 1.1</h3>
  <h3>Subsection 1.2</h3>
    <h4>Sub-subsection 1.2.1</h4>

<h2>Section 2</h2>
  <h3>Subsection 2.1</h3>
Rule: Heading hierarchy logical honi chahiye. H1 → H2 → H3 → H4. Level skip mat karo.

❌ Galat Hierarchy (Level Skip)

<h1>Title</h1>
<h4>Section</h4>  <!-- ❌ H2, H3 skip -->

❌ Galat Hierarchy (Multiple H1)

<h1>Title 1</h1>
<h1>Title 2</h1>  <!-- ❌ Sirf ek h1 per page -->

4. Headings vs Visual Sizes

Common mistake: Log headings ko sirf size ke liye use karte hain (badi text dikhane ke liye). Lekin headings ka semantic meaning hai — CSS se size control karo, heading se structure.

❌ Galat

<h4>Bada text dikhane ke liye</h4>  <!-- Semantic galat -->

✅ Sahi

<h2 style="font-size: 3rem;">Section</h2>  <!-- Level sahi, size CSS se -->

5. SEO Impact

Google headings ko page structure samajhne ke liye use karta hai. H1 sab se important, phir H2, H3, etc.

SEO Rules:

  • Ek H1 per page — primary keyword include karo
  • H2 — major topics, secondary keywords
  • H3 — subtopics, long-tail keywords
  • Natural hierarchy — skip mat karo
  • Keywords headings mein naturally use karo
  • Descriptive ho, generic nahi ("Introduction" better than "Section 1")

6. Accessibility Impact

Screen readers headings se navigation karte hain. Users shortcut keys (H key) se ek heading se doosri par jump karte hain.

A11y Rules:

  • Ek H1 per page (page ka naam)
  • Logical hierarchy (skip mat karo)
  • Descriptive text (screen reader user ke liye)
  • Empty headings mat use karo
  • Headings sirf structure ke liye, styling ke liye nahi

12. Modern Considerations

Outline Algorithm (Deprecated)

HTML5 mein ek time plan tha ke multiple h1 ho sakte hain sections ke saath. Lekin yeh kabhi implement nahi hua. Best practice abhi bhi: ek h1 per page.

Search Engine Behavior

  • Google: H1 = important ranking factor
  • Google: H2-H6 = semantic structure
  • Keywords in headings > keywords in paragraphs

Screen Reader Behavior

  • NVDA: H key se next heading
  • JAWS: Heading list (Insert + F6)
  • VoiceOver: Rotor (VO + U)
  • Mobile: Swipe navigation
