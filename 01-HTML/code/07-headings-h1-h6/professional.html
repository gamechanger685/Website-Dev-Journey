Complete Guide to HTML Headings: SEO, Accessibility & Best Practices

Headings HTML document ka backbone hain. Yeh sirf text ko bada karne ke liye nahi hain — yeh document ki structure, SEO, aur accessibility ke liye critical hain.

What Are HTML Headings?

HTML mein 6 heading levels hain: <h1> se <h6> tak. Har level document ki hierarchy mein ek role play karta hai.

Heading Levels

H1 sab se important hai (page title), H6 sab se kam. Hierarchy logical honi chahiye.

Visual vs Semantic

Heading ka size CSS se control hota hai, lekin semantic meaning tag se aata hai. Size ke liye heading change mat karo.

Heading Hierarchy

Proper hierarchy document ko scannable aur accessible banati hai.

Correct Pattern

<h1>Page Title</h1>
  <h2>Section</h2>
    <h3>Subsection</h3>
      <h4>Sub-subsection</h4>

Why It Matters

For SEO

Google headings ko page structure samajhne ke liye use karta hai.

For Accessibility

Screen readers headings se navigate karte hain (H key).

SEO Best Practices

Headings SEO ka important on-page factor hain.

Rules

Rule 1: Ek H1 per page.
Rule 2: Logical hierarchy (skip mat karo).
Rule 3: Descriptive text (generic nahi).
Rule 4: Keywords naturally use karo.

Examples

❌ Bad

<h1>Home</h1>
<h1>Welcome</h1>  <!-- Multiple H1 -->
<h4>About</h4>    <!-- Level skip -->

✅ Good

<h1>Abu Bakar — Full Stack Web Engineer</h1>
<h2>About Me</h2>
<h3>Skills</h3>

Accessibility Guidelines

Screen reader users headings se document navigate karte hain.

Shortcuts

  • NVDA: H key = next heading
  • JAWS: Insert + F6 = heading list
  • VoiceOver: Rotor = heading navigation

Requirements

  • Har section ko heading do
  • Logical order maintain karo
  • Empty headings mat use karo
  • Descriptive text

Common Mistakes

Multiple H1 Tags

Sirf ek H1 per page hona chahiye — page ka main topic.

Skipping Levels

H1 se H4 par jump mat karo. H2, H3 beech mein rakho.

Styling with Headings

Bada text dikhane ke liye headings mat use karo. CSS se size control karo.

Conclusion

Headings sirf decoration nahi — document ka structure hain. SEO, accessibility, aur user experience — teenon ke liye critical.

Proper hierarchy follow karo, ek H1 rakho, aur descriptive text use karo.
